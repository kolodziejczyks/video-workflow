# Polish video workflow

Turn Polish recordings into reviewed short clips using local transcription and native CapCut MCP projects.

Start with [AGENTS.md](AGENTS.md), then [the current handoff](docs/STATUS.md). These identify the working project, accepted Montra caption style, approval boundaries, local assets and remaining work. [Local setup](docs/local-setup.md) covers the tools and commands.

The user confirmed native CapCut 9.6 opening/playback and reviewed the Montra captions positively. Montage review and final export/publishing remain pending.

Active code is in `scripts/`; the upstream MCP extension is preserved in `patches/`. The experimental source selection is in `config/current-edit-plan.json`. Media and generated assets stay outside Git under `samples/` and `work/`.
